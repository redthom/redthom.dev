# projects

redthom/Triplo · README

Triplo

  • odin
  • raylib
  • playable prototype

A two-player digital version of Viktor Bautista i Roca's board game. Players slide pawns across a 19-tile hexagonal board, then relocate an edge tile, racing to get all three pawns onto neighbouring tiles.

  • Turn flow driven by an explicit game-state machine: menu, pawn move, tile move, game over
  • Board, pawn, and tile logic written from scratch in about 1,000 lines of Odin
  • Rendering and mouse input through raylib
